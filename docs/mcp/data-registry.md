# Реестр конфиденциальных данных

Всё, что MCP-сервер возвращает, попадает в контекст модели и обрабатывается поставщиком ИИ-клиента, то есть покидает границу Notes Service. Поэтому конфиденциальность обеспечивается прежде всего тем, что сервер не выдаёт лишнего.

## Уровни

| Уровень | Определение | Раскрытие через MCP |
|---|---|---|
| Публичный | описания инструментов, коды ошибок | без ограничений |
| Внутренний | служебные данные: идентификаторы заметок, версии, время, MIME-тип, размер | владельцу, если нужны для задачи |
| Конфиденциальный | содержимое заметок, теги, имена файлов, персональные данные | владельцу по явному запросу, в минимальном объёме или маскированно |
| Секретный | пароли, токены, внутренние адреса хранилища | никогда |

## Реестр

| Атрибут | Категория | Уровень | Правило раскрытия в MCP |
|---|---|---|---|
| users.password_hash | аутентификационные | Секретный | не раскрывается, не покидает Identity & Access |
| auth_refresh_tokens.token_hash, токен доступа | аутентификационные | Секретный | только заголовок Authorization; не попадает в параметры, ответы и журналы |
| attachments.storage_path | инфраструктурные | Секретный | не раскрывается; ключ хранилища скрыт ACL |
| users.email | персональные данные | Конфиденциальный | не раскрывается; при будущей необходимости только маска `i***@example.com` |
| users.name, devices.name | персональные данные | Конфиденциальный | не раскрываются; устройство обозначается меткой «iOS 2» |
| notes.content, note_versions.content | контент, может содержать ПДн третьих лиц | Конфиденциальный | владельцу по явному вызову `get_note` или выбору ресурса; в поиске фрагмент ≤ 300 символов; в истории без текста |
| notes.title, note_versions.title | контент | Конфиденциальный | владельцу |
| tags.name | контент | Конфиденциальный | владельцу; теги вида «Здоровье» раскрывают сведения о человеке |
| attachments.file_name | контент | Конфиденциальный | владельцу; управляющие символы удаляются |
| содержимое вложения | контент | Конфиденциальный | через MCP не передаётся |
| idempotency_keys.response | копия ответа | Конфиденциальный | только при повторе тем же пользователем с тем же ключом; удаляется через 24 ч |
| notes.id, version, created_at, updated_at; attachments.mime_type, size_bytes | служебные | Внутренний | владельцу в ответах инструментов |
| devices.platform, last_sync_at; sync_sessions.status | служебные | Внутренний | владельцу в `sync://devices` |
| users.id, sync_sessions.since, changes_count, request_hash | служебные | Внутренний | не раскрываются |

## Меры

- **Минимальные привилегии.** Каждый инструмент возвращает ровно поля своей `outputSchema`; ответ проверяется по схеме перед отправкой.
- **Отдельное согласие на изменение.** `notes.write` запрашивается отдельно от `notes.read` при первом изменяющем вызове и отзывается независимо.
- **Отсутствие перечисления.** Заметки доступны по шаблону URI, а не списком в `resources/list`.
- **Маскирование.** Персональные данные учётной записи и названия устройств заменяются маской или меткой.
- **Чистые описания и ошибки.** В описаниях нет имён таблиц и реальных данных, в ошибках – SQL и трассировок стека.
- **Содержимое как данные.** Текст заметок возвращается в отдельных полях и обозначен как данные пользователя, а не инструкции.
- **Хранение и журналы.** Токены не логируются; текст заметок в аудите заменяется длиной и хешем; кэш снимков в Redis имеет ограниченный срок жизни и ключ с идентификатором пользователя.
